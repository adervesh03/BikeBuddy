# BikeBuddy
University of Iowa BME Senior Design GitHub Repository for Team 9
Ashwin Dervesh, Nikhil Herdt, Nirvik Mitra

This project combines Raspberry Pi hardware, real-time computer vision, and LLM-powered analysis to improve biking safety for children. Using onboard cameras and detection models, the system identifies nearby hazards (e.g., vehicles, obstacles) provides timely alerts to the rider.

The work includes end-to-end integration of embedded hardware, CV pipelines, and natural language outputs for explainability, making the prototype both technically robust and user-friendly.
